# ConnectAR

AR-помощник для сборки компьютера. Наведите камеру смартфона на материнскую плату — ConnectAR распознает её, подсветит разъёмы и подскажет, что куда подключать. Чек-лист проведёт по сборке шаг за шагом.

![AR-помощник для сборки ПК](AR-помощник%20для%20сборки%20ПК.png)

## Возможности

- **AR-распознавание платы** — разъёмы подсвечиваются прямо на реальной плате, следующий шаг сборки выделен.
- **Опрос «Ваша сборка»** — память, накопители (NVMe, SATA SSD, HDD), видеокарта, вентиляторы, тип блока питания; чек-лист и подсветка подстраиваются под ответы.
- **Подсказки** — пошаговые действия, предупреждения, куда подключается кабель со стороны блока питания и ссылка на страницу руководства.
- **Заморозка кадра** — зафиксируйте кадр с метками и спокойно изучайте его с зумом.
- **Фото-режим** — работа по снимку платы, если AR недоступен.
- **Чек-лист полной сборки** — от установки процессора до первого запуска в BIOS, по этапам; прогресс сохраняется на устройстве.

Поддерживаемая плата: **Gigabyte B450 AORUS M (rev. 1.x)**.

## Структура

| Папка | Что внутри |
|---|---|
| [`ios/`](ios) | iOS-приложение (SwiftUI, ARKit) |
| [`android/`](android) | Android-приложение (ARCore) |
| [`web/`](web) | Веб-версия на MindAR, GitHub Pages |
| [`shared_boards/`](shared_boards) | Общие данные плат для всех клиентов |
| [`docs/`](docs) | Документация и [дизайн](docs/design-doc.md) |

Данные плат редактируются только в `shared_boards/`. Проверка: `node shared_boards/scripts/validate.mjs`.

## CI

`ios.yml` — тесты и сборка iOS · `shared-boards.yml` — валидация данных плат · `web.yml` — валидация данных, тесты Vitest, компиляция целей MindAR и деплой на GitHub Pages.
