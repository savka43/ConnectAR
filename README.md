# ConnectAR

ConnectAR — разрабатываемое AR-приложение для помощи в сборке компьютера. По фотографии материнской платы и её разъёмов приложение будет показывать, какие компоненты и кабели куда подключать, дополняя изображение наглядными подсказками.

Планируемые возможности:
- Распознавание материнской платы и её разъёмов по фотографии.
- AR-подсказки по установке компонентов и подключению кабелей.
- Составление чек-листа сборки компьютера с отметками о выполненных шагах.
